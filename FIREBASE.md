# Firebase — надёжный чат для сайта

Сейчас чат работает через **ntfy.sh**. Он бесплатный, но режет запросы по IP (ошибка 429),
если много людей с одного интернета (универ, мобильный оператор, офис).

**Firebase** решает эту проблему: бесплатный тариф, real-time, без лимита на пользователей.

---

## Как подключить (10 минут)

### 1. Создай проект
1. Открой **https://console.firebase.google.com**
2. Нажми **«Добавить проект»** (Add project)
3. Название: `nebula-visuals`
4. Google Analytics — **выключи** (не нужен)
5. **Создать проект**

### 2. Включи базу данных
1. Слева в меню: **«Сборка»** (Build) → **«Realtime Database»**
2. Нажми **«Создать базу данных»**
3. Расположение: выбери ближайший (например `europe-west1`)
4. Режим безопасности: **«Начать в режиме тестирования»** (Test mode)
   - В тестовом режиме доступ открытый — для публичного сайта это нормально
   - Позже можно закрыть правилами
5. **Создать**

### 3. Скопируй ссылку на базу
На странице базы данных вверху будет URL вида:

```
https://nebula-visuals-default-rtdb.firebaseio.com
```

### 4. Вставь ссылку в сайт

Открой файл `public/chat-backend.js` и найди:

```js
var FIREBASE_DB_URL = '';   // ← вставь сюда
```

Замени на:

```js
var FIREBASE_DB_URL = 'https://nebula-visuals-default-rtdb.firebaseio.com';
```

### 5. Задеплой
```bat
cd /d D:\NebulaVisuals\site
git add -A
git commit -m "Firebase backend for chat"
git push origin main
```

Vercel соберёт автоматически. Через минуту чат будет работать через Firebase.

---

## Как проверить что работает

Открой https://nebulavisuals-public.vercel.app/ → зайди в чат → отправь сообщение.
В консоли Firebase в разделе **Realtime Database** должны появиться данные.

---

## Если хочешь закрыть базу (после проверки)

В **Realtime Database** → вкладка **Правила** → замени на:

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

Это то же, что тестовый режим, но постоянно.

Для приватной базы (только авторизованные) нужна будет авторизация Firebase — это уже
сложнее, для публичного чата не требуется.

---

## Что где хранится

| Путь | Что |
|---|---|
| `chat/{timestamp-id}` | Сообщения |
| `state` | Закреплённое сообщение (пин от qqc0d) |
| `presence/{ник}` | Кто онлайн (ник → время) |

---

## Откат на ntfy (если что-то не так)

Просто очисти `FIREBASE_DB_URL` в `chat-backend.js` → задеплой → чат вернётся на ntfy.
